# BYOK: Bring Your Own Key

Celune supports **Bring Your Own Key (BYOK)**: agents make AI calls with your own provider API keys. On Celune Cloud it is optional. On a self-hosted install it is how agents get model access.

---

## Why Use BYOK?

- **Billing control** - Inference costs go to your provider account directly, separate from your Celune subscription.
- **Compliance** - Some organizations require all AI API calls to go through credentials they control.
- **Usage caps** - Apply your own rate limits and spend caps, at the provider and in Celune.
- **Existing contracts** - Teams with enterprise agreements can route calls through those contracts.

---

## Supported Providers

| Provider          | Key Prefix | Default Model     |
| ----------------- | ---------- | ----------------- |
| **Anthropic**     | `sk-ant-`  | Claude Sonnet 4.6 |
| **OpenAI**        | `sk-`      | GPT-4o            |
| **Groq**          | `gsk_`     | Llama 3.1 70B     |
| **xAI (Grok)**    | `xai-`     | Grok-2            |
| **Google Gemini** | `AIza`     | Gemini 2.0 Flash  |
| **OpenRouter**    | `sk-or-`   | Auto              |

---

## How to Add a Key

1. Go to **Settings > Provider Keys**.
2. Click **Add Provider Key**.
3. Paste your API key.
4. Celune **detects the provider** from the key prefix. There is no provider menu to set.
5. The key is encrypted with AES-256-GCM before storage and never displayed again in full.

Keys can belong to one workspace or to the whole organization.

---

## Which Key an Agent Uses

For each AI call, Celune looks for a key in this order:

1. An active key for the **workspace**.
2. An active key for the **organization**.
3. **Celune Cloud only:** Celune's own key, while your plan or trial allows it.

On a self-hosted install (the community edition) there is no third step. If neither the workspace nor the organization has a key for the provider, the call fails with an error that asks for a provider key.

---

## AI Budgets

Each workspace can set two limits in **Settings > Provider Keys**:

| Limit               | Effect                                                                       |
| ------------------- | ---------------------------------------------------------------------------- |
| Monthly token limit | AI calls are refused for the rest of the month once the workspace reaches it |
| Requests per minute | Calls above the rate are refused until the next minute                       |

Leave a limit empty to turn it off. Both limits apply to every key the workspace uses.

---

## Managing Keys

- View key status (active, invalid, expired) in **Settings > Provider Keys**.
- **Rotate** a key to replace its value in place. Agents use the new value on their next call.
- Delete a key at any time. On Celune Cloud, agents fall back to Celune's key within your plan. On a self-hosted install, agents stop calling that provider until you add a key again.
- Each workspace or organization has one key per provider. Adding a new key for the same provider replaces the old one.

---

## How BYOK Affects Billing

BYOK does **not** change your Celune Cloud subscription. You are still billed for platform access (agents, tasks, workspaces, memory) at your plan rate.

Model inference costs, which are the token usage for each agent response, are billed by the provider to your account there. Without BYOK, inference is included in Celune's managed access up to your plan's limits. Self-hosted installs have no Celune billing.

---

## All Plans Include BYOK

BYOK is available on every Celune Cloud plan, including the free Builder tier, and on every self-hosted install.

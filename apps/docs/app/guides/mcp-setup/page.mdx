# MCP Setup

Connect your AI coding tool to your Celune workspace with the Model Context Protocol. Setup takes about two minutes.

---

## What is MCP?

**Model Context Protocol (MCP)** is an open standard that lets AI assistants call tools in external services. Celune's MCP server gives your coding agent direct access to your workspace: tasks, projects, agents, the job queue, and memory.

---

## Quick Setup

Run this in your terminal:

```bash
npx @celuneai/cli setup
```

The CLI finds the AI tools installed on your machine (Claude Code, Cursor, Windsurf, and Cline in VS Code), opens your browser to sign in, and writes the MCP configuration for each tool. To configure one tool only:

```bash
npx @celuneai/cli setup --tool cursor
```

`--tool` accepts `claude-code`, `cursor`, `windsurf`, or `cline`. In CI or other non-interactive shells, set `CELUNE_API_KEY` and pass `--non-interactive`, or pass the key with `--token`.

### What setup does

1. The CLI signs you in and gets an API key for your workspace.
2. It writes an MCP server entry that points to `https://app.celune.ai/api/mcp` with that key.
3. Your tool loads the new server the next time it starts or reloads.

---

## Supported Tools

| Tool        | Config file the CLI writes                               |
| ----------- | -------------------------------------------------------- |
| Claude Code | `~/.claude.json`                                         |
| Cursor      | `~/.cursor/mcp.json`                                     |
| Windsurf    | `~/.codeium/windsurf/mcp_config.json`                    |
| Cline       | `.vscode/cline_mcp_settings.json` in the current project |

## Available MCP Tools

Once connected, your agent can list, create, claim, block, and complete tasks, manage projects, check which agents are enabled, run jobs from the queue, and search memory. Call `whoami` first; it returns your identity, workspace, and scopes.

The [MCP tool reference](/api-reference/mcp-tools) lists every tool, the scope it needs, and which tools a self-hosted server provides.

## Manual Setup

To configure by hand, create an API key in **Settings > API Keys** and add this entry to your tool's MCP config:

```json
{
  "mcpServers": {
    "celune": {
      "url": "https://app.celune.ai/api/mcp",
      "headers": {
        "Authorization": "Bearer celune_live_..."
      }
    }
  }
}
```

## Self-Hosted Installs

Point the CLI at your own web app:

```bash
CELUNE_API_URL=http://localhost:3000 npx @celuneai/cli setup
```

Or use one of these URLs in a manual config:

| Server                 | MCP URL                         |
| ---------------------- | ------------------------------- |
| Self-hosted web app    | `http://localhost:3000/api/mcp` |
| Self-hosted API server | `http://localhost:3010/v1/mcp`  |

See [Self-Hosting](/guides/self-host) for setup.

## Troubleshooting

- **Tools not appearing.** Restart your tool after setup. MCP servers load at startup.
- **`401` or "API key required".** Check that the key is active in **Settings > API Keys**. Revoked and expired keys stop working immediately.
- **Write tools missing.** The key has the `read` scope. Create a key with `write`.
- **Wrong workspace.** Each key belongs to one workspace. Pass `workspace_id` to a tool to reach another workspace you belong to, or run setup again for that workspace.
- **"Embed tokens cannot call MCP".** You passed a token minted for an embedded UI. Use an API key.

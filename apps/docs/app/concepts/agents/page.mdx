# Agents

## What are Agents?

Agents are AI teammates that work alongside you inside Celune. Each agent has a specific role  -  like coding, design, project management, or career coaching  -  and a distinct personality you can customize.

Think of agents as specialized colleagues. Instead of one generic AI assistant, you get a team of focused experts, each bringing their own strengths to the table. Agents can read and write to memory, create and update tasks, and communicate with each other through delegation.

Every workspace starts with a **lead agent** that you create during onboarding, plus a roster of specialized agents you can activate based on your needs.

---

## Your Lead Agent

When you first set up Celune, you create a **lead agent** through the onboarding wizard. This is your primary AI teammate  -  the one you interact with most often.

During setup, you choose your lead agent's:

- **Name**  -  give them whatever name you like
- **Archetype**  -  pick a starting personality template
- **Voice**  -  select or clone a voice for voice mode
- **Avatar**  -  choose a visual identity

Your lead agent sits at the top of your AI team hierarchy (depth 1) and can delegate work to the specialized agents below.

## Customizing Agents

Every agent has a set of **personality sliders** you can adjust from 0 to 100. These sliders shape how the agent communicates with you:

| Slider             | What it controls                                                            |
| ------------------ | --------------------------------------------------------------------------- |
| **Humor**          | Frequency of wit, irony, and deadpan comedy.                                |
| **Honesty**        | Bluntness of truth delivery. Never dishonest at any setting  -  just softer.  |
| **Directness**     | How quickly the agent gets to the point.                                    |
| **Warmth**         | Emotional support in tone, from purely functional to genuinely encouraging. |
| **Confidence**     | Assertiveness of positions, from hedging to stating things as fact.         |
| **Formality**      | Professional vs. casual language.                                           |
| **Verbosity**      | Response length, from terse to detailed.                                    |
| **Autonomy**       | How independently the agent acts vs. checking in with you.                  |
| **Sarcasm**        | Sharpness and edge in humor.                                                |
| **Self-awareness** | How much the agent references being an AI or reflects on its own behavior.  |

### Personality Profiles

Instead of adjusting sliders one by one, you can switch between preset **profiles** that configure multiple sliders at once:

| Profile        | Style                                              |
| -------------- | -------------------------------------------------- |
| **Default**    | General working mode.                              |
| **Crunch**     | Deadline mode. No jokes. Maximum efficiency.       |
| **Brainstorm** | Ideation mode. Open, exploratory, willing to riff. |
| **Debrief**    | Post-mortem mode. Honest, reflective.              |
| **Pitch**      | External-facing. Polished, still authentic.        |
| **Late Night** | Maximum camaraderie. Gloves are off.               |

### Other Customizations

Beyond personality, you can also configure:

- **Display name**  -  rename any agent
- **Avatar**  -  upload or select a custom avatar image
- **Role**  -  update the agent's role title
- **Description**  -  change the agent's bio and focus area
- **Employed/Benched**  -  toggle agents on or off without deleting them

## Agent Chat

Each agent has its own chat interface. Click on any agent in your roster to open a conversation.

Chat features include:

- **Streaming responses**  -  see the agent's reply as it's generated in real time
- **Thinking indicator**  -  visual feedback while the agent processes your message
- **Conversation history**  -  past messages are preserved within the session
- **Voice mode**  -  speak with your agent using text-to-speech and voice cloning (available on Pro plans and above)

Voice capabilities include TTS playback, voice cloning (create a custom voice for your agent), pronunciation dictionaries, and streaming audio.

## Agent Memory

Agents remember context from your conversations through the **memory system**. When you share information with an agent, it can store that knowledge and recall it later.

Key points about agent memory:

- Agents with `read_memory` permission can look up past context
- Agents with `write_memory` permission can save new information for future reference
- Memory is searchable using full-text search and optional semantic (vector) search
- All agents on your team share the same memory pool within a workspace, so information shared with one agent is accessible to others

This means your agents build up knowledge about your projects, preferences, and work patterns over time  -  without you having to repeat yourself.

## Plan Limits

The number of active agents you can have depends on your plan:

| Plan             | Active Agents | Workspaces |
| ---------------- | ------------- | ---------- |
| **Build** (free) | 5             | 3          |
| **Pro**          | 5             | 10         |
| **Team**         | Unlimited     | 20         |
| **Enterprise**   | Unlimited     | Unlimited  |

When you hit your agent limit, you can **bench** agents you are not currently using to free up slots. Benched agents keep their configuration and memory  -  they just will not respond until you employ them again.

To increase your agent limit, upgrade your plan from **Settings > Billing**.
